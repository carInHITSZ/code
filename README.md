# 竞赛代码仓库

本仓库包含两项国家级竞赛获奖项目的完整代码与获奖证书。

---

## 项目一：TLD7002_TC264_Demo

**第十九届全国大学生智能汽车竞赛 — 摩托组 — 全国一等奖** 🏆

基于 Infineon TC264 双核处理器的智能摩托车控制系统，集成了扩展卡尔曼滤波姿态解算、视觉识别、三串级差速平衡控制与 TLD7002 灯光秀。

详细说明见 [TLD7002_TC264_Demo/README.md](TLD7002_TC264_Demo/README.md)

> 证书：[智能车国一等奖.pdf](智能车国一等奖.pdf)

---

## 项目二：615142

**第七届人工智能算法精英大赛 — 全国一等奖** 🏆

基于 ROS 的自主移动机器人系统，融合云端视觉语言大模型（VLM）、SLAM 导航、路径规划、计算机视觉与语音交互，完成多阶段复杂任务挑战。

详细说明见 [615142/README.md](615142/README.md)

> 证书：[第七届人工智能算法精英大赛国一等奖.png.pdf](第七届人工智能算法精英大赛国一等奖.png.pdf)
